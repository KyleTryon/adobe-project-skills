# 6. Project panel: bins, project items, master clips, media

[Spec contents](README.md) · status tags: [§0](README.md#0-conventions)

Recipes and object templates: [`media-and-bins.md`](../media-and-bins.md).

1. **Tree.** `RootProjectItem` ("Root Bin") and each `BinProjectItem` list children in `ProjectItemContainer/Items/Item` (ObjectURef), with no parent pointer [O: steps 01–23 #panel.tree]. Every ClipProjectItem MUST appear in exactly one `Items` list [O: steps 01–23 #panel.clip-item-once]. An empty bin has no `Items` element [O: step 00 #panel.empty-bin-no-items]. Moving an item edits the two `Items` lists only; Premiere re-indexes the old list, rewrites the remaining items' `project.icon.view.grid.order` (view state) and drops it from the moved ones [O: steps 01→02 #panel.move-item].
2. **ClipProjectItem** → `MasterClip`. The panel name is `ProjectItem/Name`. An item is a sequence when its MasterClip's clips have a `*SequenceSource`; there is no type field [O: steps 03–23 #panel.sequence-item]. A non-media file (a `.txt`) imports as a **`FileProjectItem`** (ObjectUID, ClassID `b28f14fe-793f-45be-bb28-fb82644995f4`): a `ProjectItem` (label `BE.Prefs.LabelColors.Unknown`, `Name`) and an absolute `FullPath`, with no MasterClip, Media or `RelativePath` [O: steps 00→01 #panel.file-project-item].
3. **MasterClip** `Clips`, in order: for media the VideoClip (if any) then the AudioClip; for sequences the AudioClip then the VideoClip; then a TranscriptClip if Speech to Text ran [O: steps 01–23 #panel.masterclip-clips-order]. A sequence clone MUST share media MasterClips, not copy them [V: step 17-gen #panel.clone-shares-masterclips].
4. **Media** (ObjectUID) of an imported file is one file [O: steps 01–23 #panel.media-one-file]:
   - `ActualMediaFilePath` = `FilePath` (absolute) and `RelativePath` locate it; relinking MUST change all of them [O: steps 01–23 #panel.media-paths].
   - `RelativePath` is relative to the folder the .prproj was **saved** in, rewritten on every save; the absolute paths are not. Step 04 was saved one folder up: `./media/clip-a.mp4` there, `../media/clip-a.mp4` in the steps before and after it [O: steps 03→04, 04→05 #panel.relative-path]. A writer that writes a project to another folder SHOULD rewrite `RelativePath` the same way.
   - Premiere-saved Media of a file always carry probe caches (`ModificationState`, `ContentAndMetadataState`, `CCFileModTime`, the AudioStream's `ConformedAudioPath`/`PeakFilePath`) [O: steps 01–23 #panel.media-probe-caches]. Keep them when editing; Media written without them isn't covered ([§18](18-not-observed.md)).
5. **Streams:** `VideoStream` (duration, rate, size, `CodecType` FourCC, alpha) and `AudioStream` (duration, layout, cache paths) [O: steps 01–23 #panel.streams]; `DataStream` on a transcript's Media [O: steps 19–23 #panel.data-stream].
6. **Sources:** `VideoMediaSource`/`AudioMediaSource` (→ Media) and `VideoSequenceSource`/`AudioSequenceSource` (→ Sequence) carry `OriginalDuration`, which on a sequence source is not its length ([§7.4](07-sequences.md#74-length)) [O: steps 03–23 #panel.sources-original-duration].
7. **Import** adds the file's whole chain ([§4](04-object-graph-and-project.md#4-object-graph)) and changes only the target bin's `Items` and `Project` [O: steps 00→01 #panel.import]: 18 top-level objects for video with stereo audio, 9 for video only (including stills), 15 for stereo audio. The MasterClip gets no Node ID ([§2.4](02-document-structure.md#24-allocating-identities)), its clips an empty Markers object ([§13](13-markers.md#13-markers)).
