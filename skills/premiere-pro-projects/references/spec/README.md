# Premiere Pro project file (.prproj) format

**A reverse-engineered specification.** Adobe doesn't publish this format. Everything here was read from project files saved by Premiere Pro, cross-checked across files, and in places confirmed by writing a file and opening it in Premiere. Treat it as a description of what Premiere does, not as Adobe's contract.

## 0. Conventions

**Every claim is proven.** Each rule carries one tag, and each tag names the check that proves it:

- **O, observed**: Premiere wrote it. `[O: steps 05→06 #edits.split]` means the check `edits.split` passes on the diff of those two saves.
- **V, verified**: the scripts write it and Premiere opened the result. `[V: step 13-gen #transitions.fade-in]` cites a script-written step (`NN-gen-*`) that was opened and checked in Premiere.

`tests/premiere-pro/test_rules.py` runs every check on exactly the steps its tag cites, and fails if a tag has no check, a check fails, or a citation names a step that doesn't exist. Anything not proven isn't in the spec: [§18](18-not-observed.md) lists what isn't covered, and the repo's backlog (`fixtures/premiere-pro/generated/BACKLOG.md`) holds the unproven ideas waiting for a step.

**Citations** name steps from the demo project (00–23): `steps/NN-name.prproj` is a save after one action. `step 11` = in that save; `steps 01–11` = in every save in the range; `steps 05→06` = in the diff of those saves (`scripts/prproj.py diff steps/05-add_clip_b.prproj steps/06-cut.prproj`). The steps are one small project, so a rule is only as general as its citation.

**MUST / SHOULD.** "MUST" marks something every cited Premiere save satisfies and that a writer must preserve; "SHOULD" marks Premiere's habit, which a writer ought to follow to keep diffs small, but whose violation hasn't been shown to break loading.

**Notation.** Paths are relative to the object described: `ClipTrackItem/TrackItem/End` is `End` inside `TrackItem` inside `ClipTrackItem`. `{ID}` = a new ObjectID, `{UID}` a new ObjectUID, `{GUID}` a new random UUID as text.
