# 17. Premiere's load and save behaviour

[Spec contents](README.md) · status tags: [§0](README.md#0-conventions)

- **Save renumbers ObjectIDs** and **reorders objects** ([§2.5](02-document-structure.md#25-object-order)) [O: steps 14-gen→15, 18-gen→19 #save.renumbers]; ObjectUIDs (except the root bin's, [§2.4](02-document-structure.md#24-allocating-identities)), `ClipID`s, `FileKey`s and Node IDs were kept across saves that deleted nothing [O: steps 00→01, 01→02, 02→03, 03→04, 04→05, 05→06, 06→07, 08→09, 09→10, 10→11, 18-gen→19, 21→22 #save.stable-identities], but one save gave every `Media` a new ObjectUID [O: steps 20-gen→21 #save.media-uids-renewed]. Never carry ObjectIDs across a save, and find Media by path, not by ObjectUID.
- **Save rewrites** the project path ([§5](04-object-graph-and-project.md#5-project-and-settings)) to wherever the copy is saved, every `Media/RelativePath` ([§6](06-project-panel.md#6-project-panel-bins-project-items-master-clips-media)) relative to it, and view state: playhead, zoom and scroll, track targeting, patching and heights, the active Effect Controls component ([§8](08-tracks.md#8-tracks), [§12.1](12-effects-and-keyframes.md#121-chains)). `prproj.py diff` hides all of these unless given `--all` [O: steps 00–11 #save.rewrites-paths-and-view-state]. `.prin` files: [§1](01-container.md#1-container).
- **Saving a script-written file** raises every `MasterClipChangeVersion` and adds bin `list.view.expanded.state.<GUID>` keys [O: steps 14-gen→15, 20-gen→21 #save.script-file-resave]. One such save also added `MediaFileHistory0` (the media's path) to each Media, `Clip/PlaybackSpeed` 1 to media clips and `BE.MasterClip.ChannelIndexToTranscribe` -1 [O: steps 20-gen→21 #save.media-history-added]. Harmless; leave them.
- **Open projects:** Premiere writes its in-memory copy on save, and on auto-save if "Auto Save also saves the current project" is on, overwriting external edits. Close the project before writing the file, or reopen it without saving.
